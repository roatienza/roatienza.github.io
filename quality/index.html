Caveats, stated plainly:

  • This is clean, synthetic, expressive TTS audio — the regime the 2026 Asonitis et al. study identifies as the hardest for reference-free MOS predictors, where single-model scores stop agreeing with human listeners. Treat any one column as a weak vote, not a verdict.
  • UTMOSv2's near-zero agreement with SCOREQ (ρ = 0.006) on this set is striking. Both are trained on MOS data, but v2's fusion features (speaker, spectrogram, text-side channels) appear to weight properties orthogonal to SCOREQ's SSL-contrastive embedding on this audio. This is exactly why the composite-reward doctrine uses an ensemble, not a single predictor.
  • DNSMOS was trained on noisy-telephony data; P.835 OVRL penalizes these full-bandwidth emotional renders (mean 3.20) while its BAK component reads 4.0+ — it is included as a background-artifact vote, not a naturalness vote.
  • WhiSQA's tight 4.13–4.95 range suggests limited spread on this clean set — it rarely punishes anything here.
