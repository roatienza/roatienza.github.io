How it works

  1. Each trial plays two clips, A then B. You can replay either as many times as you like.
  2. Pick which clip expresses the prompt's emotion better (or “no difference”).
  3. At the end the page shows a completion code like ab20261001:12s21... — copy it and send it back. The code is the whole result; no audio or answers leave your browser.

Both clips are preloaded before each trial is offered. Headphones recommended.
