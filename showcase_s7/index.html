Ear check 4 — the quality gap, diagnosed and closed (A5)

Owner verdict on ear check 3 (2026-08-28): clause chunking fixed the text — all 3 samples word-perfect — but quality is below the non-streaming version. Diagnosis (A5, measured, not guessed): UTMOS naturalness 2.92 streaming vs 3.72 offline. Ten arms isolated the mechanism by dose-response: 32 steps (+0.05), wide codec context (−0.02), soft joins (+0.01), single seed (+0.03), coherent lookahead (+0.30) all fail — but chunk size moves it monotonically: 16-frame chunks 2.92 → 48-frame 3.36 → whole-window 3.68. The gap is the chunk-causal integration structure itself — each 16-frame chunk denoises against frozen left context and pure-noise lookahead, where offline co-denoises the whole window jointly. Steps never mattered (offline at 16 steps = 3.74, same as 32).

The fix candidates on this page keep everything won so far (clause chunking, breath trim, splitter fix) and change only the chunk geometry: bigchunk48 renders each ≤18-word window in 2–3 chunks of 48 frames (UTMOS 3.36, TTFA 178 ms, still incremental streaming within a window) and onechunk renders each window in a single pass (UTMOS 3.68 ≈ offline 3.72, TTFA 182 ms — first audio after the window's full render; streaming happens between windows). Both pass the WER guard: 0 repeats everywhere, long_form 0.0%, long_deep 2.4%, long_female ≤1% (single-word ASR noise). off16/off32 are the vendor offline sampler at 16/32 steps per window — the non-streaming references.

What to listen for: pick the prompt, then compare clause (ear check 3) → bigchunk48 → onechunk → off32 back-to-back. The question: does bigchunk48 already sound like offline, or is onechunk's extra margin worth per-window (not per-chunk) emission?
