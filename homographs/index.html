One homograph fix, two models

The reading is decided once, by context. The spelling is measured per model. Same code, both engines, and nothing lost on either — which the single shared table could not do.

Updated 2026-10-30. The rule now decides by grammar and never by frequency: a bare operator, a modal, do-support or a perfect auxiliary decides read, a determiner decides wind, and an occurrence with no grammatical signal is left as written. On the held-out set that took the wrong rewrites from 17 to 0 and the default-decided share of the corpus from 26.9 % to 0. The suite numbers below are unchanged, and they are unchanged because the fix did not touch a single suite sentence — verified by diffing the two rules' text output over all 31 rows, both models: 0 differences.

The rule that shipped on 2026-10-28 helped Cs2 by +5 and hurt the 4B by −2, because one carrier table was applied to whichever model was serving. dohv works on Cs2 (437-entry byte vocabulary) and fails on the 4B, whose tokenizer splits it ['do','hv'] and says “duhiv”. The carrier was chosen by looking at it, never by asking the model. Now each model is asked.

What the fix changed in real corpus text

The corpus check reads 4 494 335 rows across four manifests. Before the fix, 26.9 % of Cs2's rewrites and 21.2 % of the 4B's had no cue in range — the frequency fallback chose the reading. After the fix that share is 0: an occurrence the table cannot decide is left as written. Cs2's rewrites went 5 188 → 13 043, which is not the direction you would guess, and the reason is below.

rewritten read reading B read:B:carrier:grammar
plain too long, didn't read
before too long, didn't reed
after too long, didn't reed
still fires, and correctly: `didn't` is do-support, so the verb is the bare infinitive /ri:d/. The old rule wrote the same string from the frequency default with no cue in range -- right answer, wrong reason.
left alone read reading A none
plain we all met for a cold read in a conference room
before we all met for a cold reed in a conference room
after we all met for a cold read in a conference room
no longer rewritten. A noun, and the old B cue list reached it anyway.
left alone read reading A none
plain i never read that
before i never reed that
after i never read that
no longer rewritten, and it is genuinely ambiguous: `never` was a PRESENT cue in the old list, which is not grammar. The lab's grammar port declines it too.
left alone wind reading A wind:A:keep_plain:grammar
plain the wind was picking up
before the whined was picking up
not rendered (text recorded, audio never made)
after the wind was picking up
no longer rewritten. The bare particle `up` was a wind-B cue, and it belonged to `picking`.
rewritten wind reading B wind:B:carrier:cue
plain The shareholders will vote to wind up the company on Friday morning.
before The shareholders will vote to whined up the company on Friday morning.
not rendered (text recorded, audio never made)
after The shareholders will vote to whined up the company on Friday morning.
still fires, and the carrier is the weak part: `whined` is right for `wind up` here, wrong before `wind down`. That is a carrier defect, not a reading defect.

The first row is the one to read carefully. didn't read is do-support, so the verb is a bare infinitive /ri:d/ — the rewrite is correct, and the previous version of this page called it a defect. The old rule reached the same string from the frequency default with no cue in range: right answer, wrong reason. The rewrite count rose because read B is now decided by modals and do-support, which transcript English uses constantly (“i'm going to read”, “do you want me to read”), and those were previously left undecided.
