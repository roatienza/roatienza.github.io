Split:
How to listen: same utterance index = same text within a split. In Compare mode play champion and baseline back to back — the UTMOS jump 2.9 → 3.8 should be audible as cleaner, more natural prosody. In SOTA mode each utterance plays the LJSpeech ground truth plus all seven models back to back. Dev and holdout are different sentences; compare quality, not content, across splits.

Protocol: SA-comp (speaker-agnostic composite) = weighted mean of normalized WER, WER2, UTMOS (weights .375/.1875/.4375) — the selection scalar; SOTA target 0.80363, win target 0.81363. FULL-comp adds speaker similarity (weights .30/.15/.35/.20 for WER/WER2/UTMOS/SIM) — reported for reference only, never a selection scalar. All SOTA comparisons use the holdout split. Champion c003: w_adv 4, w_fm 2, anchor 1.0, n_disc 1, disc_lr 5e-5, voc_lr 2e-4, lr 5e-6, unfreeze@5, floor 0.1, 20 ep, seed 1237, warm-started from the baseline Stage-B ep299. Vocoder: nanovocos student (1.53M) fine-tuned jointly. Model: 5.25M acoustic + 1.53M vocoder.

Two score provenances: the champion card and the champion row in the SOTA table use the first-run holdout evaluation (outputs/loop/v2/holdout/c003/reward.json, loop reward harness, seed 1234, n_steps 1): SA-comp 0.86106, FULL-comp 0.87594. The other six SOTA rows come from the 2026-09-05 all-LJSpeech bench run (outputs/sota_bench/comparison.json), which re-synthesized and re-scored every model under one harness; the champion's bench re-synthesis scores — SA 0.85680, FULL 0.87239 — are kept on the second card for the record. The 0.86106 vs 0.8568 difference is re-synthesis variance, not a discrepancy.

SOTA benchmark: Matcha-TTS (LJSpeech-trained) and AetherTTS are trained on LJSpeech; ZipVoice, E2-TTS, F5-TTS and Chatterbox are zero-shot models that clone the LJSpeech voice from the LJ001-0001 prompt (3 s). All scored with the same harness: faster-Whisper WER, two-ASR consensus WER2, UTMOSv2, ECAPA-TDNN speaker similarity vs the LJSpeech voice, and RTF (audio time / synth time on A100). Every model in the SOTA table synthesizes the LJSpeech voice, so SIM and FULL-comp are cross-comparable across all rows.

RTF measurement: RTF = total generated-audio duration / total synthesis time over the 30-utterance holdout set, measured per model on a single NVIDIA A100-SXM4-40GB (one model per GPU), batch size 1, warm steady-state, per-utterance deployment-style calls (zero-shot models re-encode their 3 s reference prompt on every call), seed 1234. The timed region is the full synthesis call only, bracketed by CUDA synchronization; metric computation is excluded. RTF ↑ (RPi4) (added 2026-09-08): the same protocol on a Raspberry Pi 4 (quad-core Arm Cortex-A72 @ 1.7 GHz, 8 GB RAM, CPU-only, torch 2.7.1+cpu) — no GPU; measured for the champion (11.03, i.e. ~11× faster than real time on CPU), Matcha-TTS (0.17) and VITS (0.23) — both SOTA models are slower than real time on the Pi; other models marked —.
