4. How it works

The model input is repaired, the customer's text is untouched: textnorm → dictionary respelling (model text only, tags never touched) → homograph rules → synthesis with best-of-8 takes picked by the word guard. Any word can be added to the dictionary by the measured pipeline (8-take respelling search, phone gate 8/8, PER ≤ 0.12) — that is how the demo words were fixed, and how any future miss gets fixed.
